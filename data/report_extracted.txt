Knowledge Management using Agentic AI in
Small

Scale

Networks
Abstract
Traditional Knowledge Management (KM) systems are predominantly designed for enterprise-scale
deployments,

rendering

them

operationally

complex,

prohibitively

expensive,

and

misaligned

with

the

privacy

constraints

of

small-scale

networks

and

independent

research

environments.

The

minor

phase

of

this

project

established

a

localized,

edge-hosted

document

retrieval

prototype

utilizing

a

Raspberry

Pi

5

to

ensure

strict

data

sovereignty.

However,

baseline

Retrieval-Augmented

Generation

(RAG)

pipelines

utilizing

naive

fixed-size

chunking

and

single-stage

dense

vector

search

exhibited

severe

limitations

when

processing

complex,

unstructured

optical

character

recognition

(OCR)

data.

To address these deficits, this major project thesis details the architectural evolution from a passive
storage

utility

into

an

autonomous,

agentic

knowledge

repository.

The

core

contribution

is

the

integration

of

the

ReAct

(Reasoning

and

Acting)

framework,

empowering

the

system

with

autonomous

decision-making

capabilities,

including

web

search

via

the

Serper

API

and

a

mathematical

calculator

tool.

Furthermore,

the

retrieval

pipeline

was

fundamentally

overhauled

to

improve

context

precision

and

factual

grounding.

This

was

achieved

through

the

implementation

of

Context-Aware

Metadata

Chunking,

a

Hybrid

Retrieval

pipeline

synthesizing

dense

Matryoshka

embeddings

with

BM25

sparse

lexical

search,

Cross-Encoder

reranking,

and

Maximal

Marginal

Relevance

(MMR)

for

cognitive

diversity.

System

efficacy

was

rigorously

benchmarked

using

the

RAGAS

framework.

Results

demonstrate

a

100%

Context

Recall

and

a

94.1%

Faithfulness

score

on

the

standardized

SQuAD

dataset,

validating

enterprise-grade,

agentic

artificial

intelligence

can

be

executed

securely

and

efficiently

at

the

network

edge.

Introduction
In the contemporary digital ecosystem, the proliferation of unstructured data necessitates advanced
frameworks

for

digital

archiving

and

retrieval.

Knowledge

Management

encompasses

the

systematic

processes

through

which

entities

capture,

distribute,

and

utilize

information

to

achieve

operational

and

intellectual

objectives.

The

surrounding

KM

has

historically

focused

on

enterprise

environments

characterized

by

centralized

data

warehouses

and

vast

cloud

computing

resources.
1
These
systems

prioritize

rigid

documentation

practices

serving

thousands

of

concurrent

users.

However,

these

enterprise

solutions

exhibit

severe

misalignments

when

applied

to

small-scale

networks,

home

or

independent

research

infrastructures.

The

and

to

present

to

adoption.
1
Consequently, critical information in personal environments—ranging from financial records and legal
contracts

to

academic

research—frequently

becomes

lost

within

fragmented

digital

silos.

Traditional

hierarchical

and

basic

keyword

are

fundamentally

misaligned

with

human

cognitive

recall

mechanisms,

which

rely

on

contextual

semantic

cues

rather

than

exact

alphanumeric

nomenclature.

The

absence

of

an

intelligent

retrieval

system

results

in

continuous

cognitive

overhead

and

the

degradation

of

institutional

memory.
1
To resolve these constraints, the initial minor project detailed the implementation of an edge-hosted KM
system

on

a

Raspberry

Pi

5,

guaranteeing

absolute

by

1
While the foundational hardware and secure networking mechanisms

extracted

1
This major project report details the sophisticated evolution of the system. It transitions the architecture

Literature Review
The evolution of intelligent document processing relies heavily on advancements in information retrieval
and

autonomous

agent

design.

This

Retrieval-Augmented Generation and Edge Computing RAG bridges the gap between the generalized
reasoning

of

Large

Language

Models

(LLMs)

and

domain-specific

proprietary

knowledge.

By

enforcing

a

deterministic

retrieval

step

prior

to

generative

synthesis,

RAG

grounds

the

model

in

empirical

data,

mitigating

hallucinations.

The

minor

project

established

that

running

such

pipelines

on

edge

devices

like

the

Raspberry

Pi

5

mitigates

cloud

dependency

and

latency,

provided

that

embedding

models

are

optimized

for

CPU

execution,

such

as

Matryoshka

Representation

Learning

(MRL)

architectures.
1
Hybrid Retrieval: Synthesizing Dense and Sparse Search Standard retrieval pipelines rely almost
exclusively

on

bi-encoder

dense

vector

search.

While

adept

at

capturing

broad

semantic

concepts,

dense

retrieval

frequently

fails

to

capture

exact

keyword

matches,

acronyms,

or

specific

numerical

identifiers.

Recent

studies

demonstrate

that

Hybrid

Retrieval—combining

semantic

dense

methods

with

sparse

lexical

algorithms

like

BM25—yields

superior

performance.

BM25,

a

ranking

function

based

on

term

frequency

and

inverse

document

frequency

principles,

efficiently

handles

exact

keyword

matching.

Hybrid

systems

merge

these

paradigms,

often

utilizing

algorithms

like

Reciprocal

Rank

Fusion

(RRF)

to

normalize

and

synthesize

the

disparate

scoring

outputs.
2
Cross-Encoder Reranking and Maximal Marginal Relevance While hybrid retrieval ensures high
recall,

it

frequently

sacrifices

precision.

Cross-Encoder

reranking

models

address

this

by

processing

the

query

and

the

retrieved

document

simultaneously

through

transformer

attention

layers,

capturing

highly

nuanced

interactions

that

bi-encoders

miss.

Research

from

MIT

indicates

that

adding

a

cross-encoder

to

a

retrieval

pipeline

increases

average

accuracy

by

33%

to

40%,

particularly

for

complex

or

ambiguous

queries.
3
To prevent the LLM from being starved of diverse context due to redundant documents, Maximal
Marginal

Relevance

(MMR)

is

employed.

Originally

introduced

by

Carbonell

and

Goldstein

(1998),

MMR

elegantly

balances

query

relevance

with

information

novelty,

penalizing

redundant

information

in

the

final

context

window

to

promote

a

richer,

multi-faceted

generative

response.

Agentic Frameworks and ReAct
The transition from reactive AI to autonomous systems is encapsulated by agentic frameworks. The
ReAct

(Reasoning

and

Acting)

paradigm,

proposed

by

Yao

et

al.

(2023),

synergizes

dynamic

reasoning

with

task-specific

actions.

Unlike

models

that

only

generate

a

ReAct

agent

iteratively

formulates

thoughts,

executes

actions

via

external

tools

(e.g.,

APIs,

calculators),

observes

the

results,

and

adjusts

its

plan.

This

tight

integration

allows

the

system

to

synthesize

internal

knowledge

with

dynamic,

external

environmental

feedback.

The most profound architectural upgrade is the transition from a passive retrieval script to the ReAct
agentic

Operating

● Web Search Integration: Integrated via the Serper API, this tool allows the agent to execute

● Mathematical Calculator: A dedicated calculator tool enables the agent to evaluate mathematical

The orchestration relies on GroqCloud's high-velocity inference Application Programming Interface
