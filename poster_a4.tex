\section{Abstract}
\justifying
Traditional Knowledge Management (KM) systems are often costly, cloud-dependent, and unsuitable for privacy-sensitive small-scale environments. This project upgrades a localized edge-hosted KM prototype into an \textbf{agentic Retrieval-Augmented Generation (RAG)} system on Raspberry Pi 5. Major enhancements include context-aware metadata chunking, hybrid retrieval (dense vectors + BM25 + RRF), cross-encoder reranking, and MMR-based diversity control. RAGAS-based evaluation reports \textbf{94.1\% Faithfulness} and \textbf{100\% Context Recall} on SQuAD.

\section{Problem Statement \& Objectives}
\subsection*{Problem}
\begin{itemize}[leftmargin=1em,itemsep=1.5pt,topsep=1pt]
    \item Fixed-size chunking breaks semantic continuity in OCR-heavy documents.
    \item Single-stage dense retrieval misses exact lexical signals.
    \item Small networks need privacy-preserving, low-cost, edge-native KM.
\end{itemize}

\subsection*{Objectives}
\begin{itemize}[leftmargin=1em,itemsep=1.5pt,topsep=1pt]
    \item Improve retrieval quality and answer faithfulness.
    \item Enable autonomous reasoning/action with tool orchestration.
    \item Maintain local-first secure deployment for data sovereignty.
\end{itemize}

\section{System Architecture (Edge Deployment)}
\subsection*{Hardware \& Network}
\begin{itemize}[leftmargin=1em,itemsep=1.5pt,topsep=1pt]
    \item Raspberry Pi 5 (8GB RAM) + 512GB NVMe SSD.
    \item Active cooling for sustained AI workloads.
    \item Tailscale (WireGuard-based) for secure remote access.
\end{itemize}

\subsection*{Baseline Flow}
\begin{enumerate}[leftmargin=1.2em,itemsep=1.5pt,topsep=1pt]
    \item Ingestion/OCR: upload or Samba share $\rightarrow$ Tesseract $\rightarrow$ metadata extraction.
    \item Embedding: segmentation $\rightarrow$ MRL embeddings $\rightarrow$ ChromaDB.
    \item Querying: FastAPI $\rightarrow$ retrieval $\rightarrow$ Groq response.
\end{enumerate}

\columnbreak

\section{Proposed Technique}
\subsection*{1) Context-Aware Metadata Chunking}
\begin{itemize}[leftmargin=1em,itemsep=1.5pt,topsep=1pt]
    \item Replaces rigid 1000-character chunking.
    \item Preserves semantic/structural boundaries.
    \item Injects metadata (title/date/section) into each chunk.
\end{itemize}

\subsection*{2) Hybrid Retrieval Pipeline}
\begin{itemize}[leftmargin=1em,itemsep=1.5pt,topsep=1pt]
    \item Dense semantic retrieval via MRL embeddings.
    \item Sparse lexical retrieval using BM25.
    \item Rank fusion via Reciprocal Rank Fusion (RRF).
\end{itemize}

\subsection*{3) Precision \& Diversity Orchestration}
\begin{itemize}[leftmargin=1em,itemsep=1.5pt,topsep=1pt]
    \item Cross-encoder reranking for query-document interaction quality.
    \item MMR to reduce redundancy and improve context diversity.
\end{itemize}

\subsection*{4) ReAct Agentic Framework}
\begin{itemize}[leftmargin=1em,itemsep=1.5pt,topsep=1pt]
    \item Multi-step reasoning with tool use.
    \item Uses web search and calculator for grounded responses.
\end{itemize}

\section{Experimental Setup}
\textbf{Evaluation Framework:} RAGAS\\
\textbf{Datasets:}
\begin{itemize}[leftmargin=1em,itemsep=1.5pt,topsep=1pt]
    \item SQuAD (100 questions)
    \item Proprietary synthetic OCR-heavy dataset (20 questions)
\end{itemize}
\textbf{Metrics:}
\begin{itemize}[leftmargin=1em,itemsep=1.5pt,topsep=1pt]
    \item Faithfulness
    \item Answer Relevancy
    \item Context Precision
    \item Context Recall
\end{itemize}

\section{Results}

\textbf{Interpretation}
\begin{itemize}[leftmargin=1em,itemsep=1.5pt,topsep=1pt]
    \item Hybrid retrieval achieved perfect recall on structured data.
    \item Cross-encoder + MMR improved precision and grounding.
    \item OCR-fragmented documents remain the main challenge.
\end{itemize}

\section{Conclusion}
The upgraded architecture demonstrates that enterprise-grade, agentic KM can run on low-power edge hardware while preserving privacy. Context-aware chunking, hybrid retrieval, reranking, and ReAct tool orchestration significantly improve retrieval quality and factual reliability.

\end{itemize}
